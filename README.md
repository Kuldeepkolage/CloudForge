# CloudForge

CloudForge is a DevOps-focused cloud-native deployment platform built to learn and implement modern DevOps practices.

## Goals

- Docker
- Docker Compose
- Kubernetes
- Jenkins CI/CD
- SonarQube
- Trivy
- Prometheus
- Grafana
- ArgoCD

## Tech Stack

### Frontend
- React
- Vite

### Backend
- Node.js
- Express

### Database
- MongoDB
